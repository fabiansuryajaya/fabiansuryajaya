# Halo, saya Fabian 👋

Fullstack developer dari **Surabaya, Indonesia**. Saya senang membangun aplikasi web yang benar-benar dipakai sehari-hari — dari kasir toko sampai bot Telegram — dan menjalankannya sendiri di homelab.

🌐 **[rakitkode.com](https://rakitkode.com)**

## 🛠️ Stack

**Bahasa:** JavaScript (Node.js) · PHP · SQL
**Data:** MySQL / MariaDB · SQLite
**Infra:** Linux · Caddy · PM2 · systemd · Cloudflare Tunnel · Tailscale
**Integrasi:** Telegram Bot API · LLM API (Claude & provider lain)
